# 07 — Checklist de aceptación

## Diseño

- [ ] Mantiene estética negra y dorada
- [ ] Se siente premium, no recargado
- [ ] Solo aparecen 3 sillones en imágenes del interior
- [ ] No aparece la fotografía del propietario
- [ ] Logo legible en desktop y mobile
- [ ] Contraste suficiente
- [ ] Responsive desde 320 px

## Contenido

- [ ] Todo en español de España
- [ ] Nombre siempre como “La 7 Barbería”
- [ ] Teléfono correcto
- [ ] Email correcto
- [ ] Asturias, España
- [ ] No se inventan precios, horarios ni dirección

## Conversión

- [ ] Booksy visible en header
- [ ] Booksy visible en hero
- [ ] Booksy visible en reserva
- [ ] WhatsApp visible en hero
- [ ] WhatsApp visible en contacto
- [ ] Sticky CTA móvil si no interfiere con accesibilidad
- [ ] Enlaces externos funcionan correctamente

## Accesibilidad

- [ ] Navegación por teclado
- [ ] Focus visible
- [ ] ALT descriptivos
- [ ] `aria-label` en iconos interactivos
- [ ] Botones con labels claros
- [ ] Contraste WCAG AA
- [ ] Menú móvil accesible
- [ ] Reduced motion respetado

## Performance

- [ ] Imágenes optimizadas
- [ ] Hero no bloquea innecesariamente
- [ ] Sin JS excesivo
- [ ] Sin fuentes innecesarias
- [ ] Lighthouse alto

## SEO

- [ ] Metadata
- [ ] OG image
- [ ] sitemap
- [ ] robots
- [ ] canonical
- [ ] estructura semántica
