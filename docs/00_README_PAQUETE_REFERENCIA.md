# La 7 Barbería — Paquete de referencia para Claude Code

Este paquete contiene la definición funcional, visual y de contenido necesaria para construir el portal web de **La 7 Barbería**.

## Objetivo

Crear un sitio web premium para una barbería en Asturias, España, con una identidad visual de lujo clásico moderno, centrada en negro, dorado y luz cálida.

El portal debe:

- Presentar la marca y los servicios.
- Transmitir una experiencia de barbería premium.
- Enviar las reservas a **Booksy**.
- Facilitar el contacto directo mediante **WhatsApp**.
- Ser completamente responsive.
- Estar escrito en **español de España**.
- Mantener una experiencia rápida, accesible y orientada a conversión.

## Regla visual principal

Las imágenes de `references/final/` son la referencia visual prioritaria.

Las imágenes de `references/original/` son material de origen y contexto.

Las imágenes de `references/archive/` son conceptos anteriores y NO deben prevalecer sobre las referencias finales.

## Decisiones definitivas

- Marca: **La 7 Barbería**
- Idioma: español de España
- Estética: lujo clásico moderno
- Paleta: negro, dorado, bronce cálido, gris y blanco
- Número de sillones visibles en la barbería: **3**
- No utilizar la fotografía del propietario en el portal
- Reservas: Booksy
- CTA directo: WhatsApp
- Email: la7barberia@gmail.com
- Teléfono / WhatsApp: +34 643 67 53 76
- Instagram: @la7barberia
- Ubicación comunicada por ahora: Asturias, España
